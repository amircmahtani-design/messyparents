Browse topics

These are the “Browse by topic” pills on the Home and Guides pages. Add a topic, give it an emoji (or upload a little icon), then tag guides with it in the guide editor. Reorder with the arrows. Adding more is fine — the pills wrap neatly onto a second line.

Our Books

Each book shows its cover on top with a short summary underneath. Upload a cover, write the summary, set the status. Reorder with the arrows.

Footer

The two lines at the very bottom of every page. Write {year} in the copyright line and it becomes the current year automatically, so it never goes stale. Links go in as [Contact us](mailto:hello@example.com). Empty a box and Save to put the original line back.

Search & AI

How the guides appear in Google, ChatGPT Search, Bing and Copilot. These are site-wide defaults — any single guide can override them in its own Search section.

What appears on a guide page

Everything except breadcrumbs is rendered below the guide panel, which is sized to fit the screen — so nothing here changes what a reader sees first. They scroll to it.

Verification

Paste the codes Google and Bing give you when you add the site. Leave blank until you have the real ones — a made-up code fails verification and stays on every page.

Publish to the web

Saving a guide updates the live site straight away. The search-engine copy — the real page at its own address, the sitemap — is rebuilt on deploy. Paste your Netlify build hook here once and this button rebuilds it on demand.

Character sessions

Each character keeps a persistent illustration session so the look stays consistent across every guide. If a character starts drifting, reset its session — the canon is re-established from your reference images on the next generation.

Reference images

The reference art is bundled with the site — 8.6MB deployed on every build for files only this panel uses. Move it to Firebase Storage and it is fetched from there instead. Run this once, on the live site, before deleting assets/img/refs/ from the repo — it copies the files from where they are now.
